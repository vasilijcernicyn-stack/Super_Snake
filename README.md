# Проект: Консольная игра "Супер Змейка"

Мой первый учебный проект, написанный вручную на языке Python с использованием системы контроля версий Git.

## 🎮 Описание игры
Это классическая игра "Змейка", адаптированная для работы прямо в текстовой консоли (терминале). Вместо графических пикселей игровое поле строится из символов:
* `#` — Стены игрового поля
* `X` — Голова змейки
* `o` — Тело змейки
* `*` — Еда (звёздочка)

## 🛠️ Что было сделано в ходе проекта:
1. Написана чистая логика массивов и игрового цикла без использования тяжелых графических библиотек.
2. Настроено рабочее окружение Python 3.12 на ноутбуке, устранены конфликты версий.
3. Проект полностью упакован в локальный архив через терминал Git.
4. Выполнен первый коммит и отправка (push) кода на GitHub.

## 🚀 Как запустить:
1. Открыть проект в PyCharm.
2. Запустить файл `main.py` (Shift + F10).
3. Управлять змейкой с помощью клавиш W (вверх), S (вниз), A (влево), D (вправо) и клавиши Enter.
